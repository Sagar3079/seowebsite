The standard

The rule for Vol. 02 was simple: nothing that looks like a template. Three disciplines hold across all twelve sites.

Direction

One art direction each

A committed palette, a deliberate type pairing, and layout geometry grounded in the business itself. The twelve read like twelve different studios — because that was the brief.

Depth

Dimension you can feel

Cursor-tilt scenes, parallax layers, CSS-built 3D objects — all transform-and-opacity, all 60fps, all quietly stepping aside when you prefer reduced motion.

Ownership

One file, fully yours

Each site exports as a single self-contained HTML document. System fonts, inline SVG, hand-written scripts. Host it anywhere; owe nobody a subscription.
